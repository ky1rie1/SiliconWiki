# 3D 实景装机 · v2.6.0

发布日期：2026-10-29。正式入口：`#/simulator3d`。

本次把模型与玻璃交互升级接入现有九步装机流程。CPU/插槽局部重新建模，其他部件保留原有教学几何并共用新的材质纹理；这不是整机所有部件的 CAD 重建。历史 `#/lab` 保留，但首页和最新网站动态指向正式装机页。

## 实现范围

- CPU 缺口顶盖、基板、蚀刻字样、简化 LGA 接触阵列、定位标记、螺钉、压框与锁杆。
- CPU 分解先打开固定机构再抬起封装；回装和重置相机使用固定插槽位置，避免跟随 CPU 的中间动画位置偏移。
- 主板丝印与走线使用单张透明纹理，金属共用 256 × 256 程序微表面纹理。触点使用实例绘制，保持静态网格合批及统一资源释放。
- 正式页浮动工具栏与步骤导航使用 CSS 透景模糊、边缘高光、指针光泽和滑动选中层。没有增加 WebGL 折射渲染通道，也不把 CSS 效果称为物理光学模拟。
- 轻量效果关闭玻璃模糊、CSS 过渡及风扇/装配动画，并临时使用省电画质；系统减少动态偏好仍受尊重。
- 同步中英文 README、三张实际页面截图与网站 v2.6.0 动态。

## 精度与数据

整机以代表性 AM5 / DDR5 / ATX 平台教学，保留 ATX 主板 305 × 244 mm 比例与已有装配方向。插槽触点数量、局部尺寸、PCB 走线与间隙均作简化，未按厂家机械图验证，不能据此判断具体产品兼容性。安装步骤的来源见 README；本次未扩大规格核验范围，也未接入实时价格或自动采集。
