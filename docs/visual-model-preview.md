# 视觉与模型样稿 · v2.6.0-preview.1

本批次实现已批准设计的第一步：可操作展厅、装配台与 CPU 插槽结构样稿。开发分支为 `codex/visual-model-preview`，网站动态同步本批次的中英文内容。发布范围只包含本次样稿及其测试、说明；工作目录中此前未完成的翻译和目录扩展不包含在该批次内。

## 查看与操作

运行 `npm run dev -- --host 127.0.0.1`，打开 `http://127.0.0.1:5173/#/lab`。也支持 `?tab=lab`。首页的“体验视觉与模型样稿”和网站“更新公告 → 查看本次样稿”均可进入。

- 展厅：整体视觉与三类硬件资料入口；装配台：模型与说明并列。
- 拖动旋转，滚轮缩放；工具栏提供键盘可用的 45° 旋转与视角复位按钮。
- 滑块和“分解观察 / 合拢观察”控制结构分离；CPU 始终是完整封装，先打开锁杆与压框，再抬起处理器。
- 可切换到现有整机模型。三档画质限制像素预算；“减少效果”关闭玻璃模糊与过渡，并使用省电画质。
- 深浅主题及中英文沿用网站已有开关。WebGL 初始化失败或上下文丢失时显示可重试提示，其余内容与导航仍可使用。

## 视觉与结构范围

以 `docs/assets/preview-concepts/home.png` 和 `studio.png` 为构图参考：暖白背景、石墨文字、低饱和金色、左侧标题或模型、右侧说明、少量玻璃浮动控件。保留项目现有 logo 和无衬线字体。实现场景使用可旋转的原创几何，而非把生成图当作产品实物或精确资产；当前仍是结构与材质试验，不是参考图的照片级复刻。

插槽局部增加 PCB 薄板、电感、电容、散热鳍片、DIMM 槽、LGA 触点、完整 CPU、压框与锁杆。共享材质与几何，重复小件使用实例，静态部件按材质合批。金属表面使用小尺寸程序纹理；没有添加依赖、外部 HDR 或模型下载。

模型尺寸、触点数量、完整 PCB 走线及间隙未经厂家机械图验证。不能以此判断实际产品兼容性。以下资料仅支持方向对齐和安装顺序，核对日期为 2026-10-29：

- [MSI CPU 安装说明](https://www.msi.com/support/technical_details/MB_CPU_Upgrade_Installation)
- [ASUS CPU 对齐与安装说明](https://www.asus.com/support/faq/1047659/)

后续精度升级需要绑定精确 SKU、可用机械尺寸及可追溯资产来源。实时数据采集仍按已批准设计后续分批执行；本批次没有接入价格接口，也没有把静态数据标为实时。
