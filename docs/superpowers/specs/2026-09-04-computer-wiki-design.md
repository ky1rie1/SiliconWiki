# SiliconWiki（芯知硬件百科）系统设计规格说明书

## 1. 项目概述
SiliconWiki（芯知硬件百科）是一个面向电脑硬件爱好者、装机新手与数码选购人群的现代化交互式硬件知识与装机指南 Web 应用。项目采用纯静态可部署架构，支持一键部署到任意域名（Vercel、Cloudflare Pages、GitHub Pages 或 Nginx），具备极致的加载速度、丰富的三维交互、权威的跑分溯源与智能的电商比价能力。

---

## 2. 核心架构与技术栈选型

* **核心框架**：React 18/19 + Vite + TypeScript
* **样式与设计系统**：Tailwind CSS + Lucide React 图标库
* **3D 渲染引擎**：Three.js（基于 WebGL 硬件加速，原生程序化建模与 PBR 材质渲染，免外部大模型文件网络加载延迟）
* **主题与色彩系统**：
  * 深色模式（Dark Tech 极客炭黑与微光夜幕）
  * 浅色模式（Clean White 极简工程白皮书）
  * 支持系统自动偏好识别与手动一键丝滑切换
* **数据存储策略**：
  * 本地强类型数据仓库（`src/data/`），零后端依赖，0 毫秒首屏加载。
  * 结构化更新扩展接口与配置导入工具。

## 3. 功能模块规划

### 模块一：硬件全景百科库 (Hardware Encyclopedia)
1. **台式机硬件**：
   * **CPU**：核心架构、P/E大小核、主频/睿频、三级缓存与 3D V-Cache 游戏神核原理、IPC、TDP、盒装 vs 散片。
   * **显卡（GPU）**：CUDA/流处理器、显存容量与位宽、DLSS 3.5/FSR 3 帧生成、显卡做工用料等级、视频输出接口。
   * **主板（Motherboard）**：Intel（Z/B/H）与 AMD（X/B/A）芯片组、板型（E-ATX/ATX/M-ATX/ITX）、供电相数、PCIe 4.0/5.0 通道分配。
   * **内存（RAM）**：DDR4 与 DDR5 性能对比、频率与 CL 时序、XMP/EXPO 超频、双通道 2/4 槽安装法则。
   * **存储（SSD/HDD）**：NVMe M.2 协议（PCIe 3.0/4.0/5.0）、TLC vs QLC 避坑、DRAM 独立缓存与 HMB、CMR vs SMR 机械盘。
   * **电源（PSU）**：额定功率计算器、80PLUS 金牌/白金认证、ATX 3.0/3.1 与 12V-2x6 防烧规范、模组走线。
   * **散热系统（Cooler）**：单双塔风冷 vs 240/360 水冷、硅脂涂抹法与**“撕膜警告”**。
   * **机箱（Chassis）**：前进后出风道设计、硬件限长限高兼容性。
2. **笔记本专项**：
   * 移动版 vs 桌面版硬件核心差异（同名不同芯解密）。
   * 功耗墙与性能释放（TGP / Dynamic Boost、残血 vs 满血）。
   * 屏幕面板素质（IPS / OLED / Mini-LED、高刷、色域、PWM 高频调光防频闪）。
   * 模具散热（VC均热板、液金安全防范）。
   * 选购定位矩阵（轻薄便携本、全能创作本、高性能游戏本、Apple MacBook 系列）。

### 模块二：多维性能天梯榜 (Benchmark Rankings)
1. **CPU 战力天梯**：
   * 支持三大排序维度：「3A 游戏帧率表现」、「多核生产力渲染」、「每瓦能效比」。
   * 支持同时比对或独立筛选桌面端与移动端标压/低压处理器。
2. **GPU 显卡天梯**：
   * 支持「1080P/2K/4K 综合游戏性能」、「光线追踪 (Ray Tracing)」、「AI 生图与深度学习算力」维度。
   * 移动端显卡与桌面端并列对比视图。
3. **PK 横向对比台**：
   * 允许用户勾选任意 2~3 款硬件，并排生成规格对比、跑分差距柱状图、功耗与选购建议。
4. **权威溯源打通**：
   * 每个型号附带外链直达：**极客湾（Geekerwan/socpk）权威天梯榜**、TechPowerUp 官方芯片数据库、PassMark / 3DMark 数据库。

### 模块三：3D 可视化交互装机教学系统 (3D Interactive Simulator)
1. **三维场景与构件**：
   * 全景 3D 电脑主机：侧透机箱（玻璃可拆）、ATX主板、CPU、双通道内存、M.2 SSD、散热器、独立显卡、电源与线缆。
   * 支持 360° 鼠标拖拽旋转、平移、双指/滚轮缩放。
2. **9 大标准分步装机引导**：
   * Step 1: CPU 安装（对齐金色三角标、防呆凹槽、压杆闭合）
   * Step 2: 内存安装（确认防呆缺口、插 2/4 槽双通道、下压听到“咔哒”声）
   * Step 3: M.2 SSD 安装（45°倾斜入槽、螺丝紧固、**撕去散热片导热胶膜**）
   * Step 4: 散热器安装（**撕下散热铜底保护膜！**、硅脂点涂、对角紧固）
   * Step 5: 主板入箱（I/O 挡板嵌入、铜柱定位、拧紧螺丝）
   * Step 6: 电源安装与主板走线（风扇朝向、24Pin 主板与 8Pin CPU 供电）
   * Step 7: 显卡安装（拆后窗挡片、掰开 PCIe 卡扣、插卡并锁螺丝、插上供电线）
   * Step 8: 机箱跳线图解（POWER SW、RESET、Power LED、USB3.0、HD Audio 防错指南）
   * Step 9: 首次开机点亮与自检（主板 Debug 灯自检顺序：CPU->DRAM->VGA->BOOT、进 BIOS 开启 XMP）
3. **高阶 3D 交互**：
   * **一键全机爆炸拆解透视 (Exploded View)**：零件平滑散开悬浮，展示整机内部三维层级。
   * **部件点击聚焦 (Focus & Inspect)**：点击零件视角平滑推进，展示装机注意事项。
4. **📺 B站保姆级实操视频接入**：
   * 整合 B 站公认优质保姆级装机教程（极客湾、硬件茶社、装机猿等官方精选视频），提供分步时间轴与直达入口。

### 模块四：硬件名词术语宝典 (Hardware Glossary)
1. **专页知识词典**：
   * 分类 A-Z 速查：CPU类（IPC/TDP/3D V-Cache/大小核）、GPU类（CUDA/显存位宽/光追/DLSS）、屏幕类（PWM调光/色域/响应延迟）、存储类（NVMe/PCIe/TLC/TBW/DRAM）、主板供电类（VRM/供电相数/XMP/EXPO）。
   * 通俗三段式排版：一句话人话解释 + 底层技术原理 + 选购避坑指南。
2. **全站智能下划线气泡 (Smart Tooltips)**：
   * 全站在出现相关术语时自动带有微光下划线，悬浮/点击即刻弹出迷你解释卡片。

### 模块五：行情趋势与智能预算配置单 (Pricing & Builds)
1. **“永不下架”的电商精准语义直达**：
   * 针对各个具体硬件型号，生成精准指向京东自营、淘宝百亿补贴、拼多多的官方实时搜索比价通道，彻底解决具体单品链接随时间失效/404的痛点。
2. **参考价格与行情风向标**：
   * 标注建议发售价（MSRP）、当前市场均价区间以及行情涨跌预警。
3. **精选预算配置单**：
   * 覆盖 3000 元（高性价比网游轻度办公）、5000 元（1080P/2K 畅玩甜点神机）、8000 元（2K 3A 旗舰高刷）、15000 元（4K 光追高阶主机）、25000 元+（顶级生产力与 AI 终极旗舰）各档位推荐，包含详细配件清单与一键复制。

### 模块六：深度全局智能搜索系统 (Enhanced Omnisearch)
1. **全局快捷呼出**：
   * 支持点击顶部搜索框，或按下快捷键 `Ctrl + K` / `/` 唤出 Spotlight / Command Palette 弹出层。
2. **多维度智能匹配**：
   * 支持模糊拼音、首字母缩写（如输入 `4070s` 自动匹配 RTX 4070 Super；输入 `xmp` 匹配内存名词；输入 `zj` 或 `装机` 匹配装机步骤）。
   * 搜索结果按类别聚合并高亮关键字：【硬件库】、【天梯跑分】、【名词术语】、【装机步骤】、【预算配置】。
   * 键盘上下键快捷选中，回车直接快速跳转到目标板块。

### 模块七：更新公告与版本日志系统 (Changelog & Announcements)
1. **入口设计**：
   * 顶部导航栏提供通知铃铛图标与带未读动效红点，点击滑出日志抽屉面板。
2. **内容记录维度**：
   * 版本号（如 v1.0.0 正式版上线）。
   * 硬件与跑分数据库新增（如：已同步 2024~2026 最新显卡与处理器基准分）。
   * 市场价格行情更新日志。
   * 新增功能与体验优化记录。

## 4. 部署与发布说明

1. **构建输出**：运行 `npm run build` 生成 `dist/` 纯静态文件夹。
2. **域名绑定**：
   * 可直接推送到 GitHub 启用 GitHub Pages，设置 Custom Domain。
   * 可直接关联 Vercel / Cloudflare Pages，在控制面板一键绑定用户自定义域名，自动配置免费 SSL 证书。
   * 亦可直接放置于云主机 Nginx 的 `html/` 目录下服务。
